二维码传输中心

v1.0.0 纯前端无网跨设备传输工具

基于动态彩色条形码与标准静态二维码构建的纯前端离线传输工具。无需 Wi-Fi、蓝牙或任何云端服务器，仅通过屏幕光线与摄像头扫描，即可在物理隔离设备间实现极速、安全的文件与文本互传。

🌟 核心特性
🛡️
完全离线与物理隔离 (Air-Gapped)： 不建立任何网络连接，零数据上云，彻底阻断远程抓包与监听风险。
⚡
双模式智能引擎： 支持 Cimbar 动态彩色条码（流式传输大文件）与高容量静态二维码（单张容纳最高 2,953 字节文本/链接）。
🚀
纯客户端高速运算： 基于 WebAssembly 与 HTML5 Canvas 硬件渲染，秒级编码解码，即开即用。
📦
单文件离线便携运行： 提供单文件独立版 HTML，直接复制到 U 盘或手机即可跨平台使用。
